## 단위와 출처

- GC 대기는 초기화를 제외한 SW/RW 회수 함수 호출 구간의 시뮬레이션 진행 시간이다. 기존 NAND 대기와 호출 중 처리한 호스트 쓰기가 포함될 수 있다.
- RW GC 횟수는 RW victim 회수 횟수이고, Partial / Full은 merge 횟수이다. 서로 단위가 달라 합산하지 않는다.
- 현재 8채널·multi-plane 설정에서 복사량 1 FTL I/O unit은 32KiB이며, 16KiB 물리 페이지 2개에 해당한다.
- GC 호출이 없으면 평균은 정의되지 않아 `—`로 표시한다.
- log225/log245 MusicFaceBook은 동일한 입력이지만 원본처럼 각각 표시했다.
